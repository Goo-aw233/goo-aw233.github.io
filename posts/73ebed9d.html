重置 IE 与 Explorer 的搜索引擎

发表于 2026-11-09 分类于 教程 ， Windows 阅读次数： 本文字数： 9.7k 阅读时长 ≈ 9 分钟
解决 Windows 10/11 禁用 Internet Explorer 后，文件资源管理器（explorer.exe）地址栏搜索仍被强制锁定或回退至百度（带 80035161 渠道号）的问题，通过绕过 EUPP 哈希校验彻底重置为 Bing、Google 或自定义搜索引擎。

前言

相关阅读：在 Windows 打开 Internet Explorer

在 Windows 10 与 Windows 11 中，即使 Microsoft 已经停用独立的 Internet Explorer 11 并重定向至 Microsoft Edge，系统底层的外壳程序（explorer.exe）在地址栏输入非路径关键词时，依然会调用遗留的 SearchScopes 注册表接口发起网页搜索

在简体中文版 Windows 镜像中，系统出厂预设了带有渠道推广标识的百度搜索（URL 包含 tn=80035161_2_dg）
如果仅通过注册表编辑器或常规脚本直接修改 SearchScopes，系统内置的 EUPP（End User Personalization Protection，终端用户个性化保护） 防篡改哈希校验机制会判定该配置失效，从而强制回滚到出厂预设的百度

使用 Windows PowerShell 脚本，可以使底层 FeatureControl 写入豁免配置关闭外壳进程的 EUPP 校验，并同步清洗 HKEY_CURRENT_USER 与 HKEY_LOCAL_MACHINE 下的所有残留项，实现彻底将资源管理器与 Internet Explorer 接口的默认搜索引擎重置为 Bing 或第三方搜索引擎

后记

  1. URL 后缀中的 pc=EUPP_ 是什么
    在切换为 Bing 后，如果在资源管理器地址栏输入内容搜索，最终打开的链接可能会附带 &pc=EUPP_ 参数
    这是 Windows 外壳组件在调用 Bing 接口时原生组装的 Partner Code（渠道归因标识），代表流量来源于 Windows 外壳环境

  2. 为什么没有通过图形界面修改的方案
    在 Windows 10/11 弃用 Internet Explorer 之后，Windows 中绝大部分 Internet Explorer 相关的窗口被删除，“管理加载项”的窗口已经被移除“搜索提供程序”选项卡
